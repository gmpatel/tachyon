Install With Downloader

  1. On the TV, install Downloader by AFTVnews from Google Play.
  2. Open it and type a code in the box on its Home tab — 7607080 or 2336338 — then select Go.
  3. When Android asks, allow Downloader to install unknown apps, then select Install.
  4. Open Tachyon from your apps and add your service.

Both codes install the same file — one from Dropbox, one from Google Drive. If one is slow, use the other.

Fire TV

Fire TV Stick, Fire TV Cube and Fire TV televisions · Fire OS 6 or newer

With the free Downloader app, type a code:

Dropbox7607080
Google Drive2336338

Install With Downloader

  1. Search for Downloader on the Fire TV and install it.
  2. Settings → My Fire TV → Developer Options → Install Unknown Apps → turn Downloader on.
  3. Open Downloader, type 7607080 or 2336338, select Go, then Install.
  4. Open Tachyon from Your Apps & Games and add your service.
No Developer Options?

Settings → My Fire TV → About, then press OK on your device’s name 7 times. Developer Options appears under My Fire TV.

If Android Stops It

“For your security, your phone isn’t allowed to install unknown apps” — select Settings, turn on Allow From This Source for your browser, go back and select Install.

Installer or Portable?

Installer

Sets Tachyon up once for your user (no admin prompt), adds it to the Start menu, starts faster and updates itself.

Portable

One .exe that runs from anywhere — a USB stick, Downloads — with nothing installed. It unpacks itself on each start.

The same app either way, with the same settings — you can switch any time.

Install

  1. Run the file you downloaded.
  2. Installer: Tachyon opens when it’s done, and from then on from the Start menu. Portable: it opens straight away.
  3. Add your service.
If Windows Stops It

“Windows protected your PC” (SmartScreen) shows for apps that aren’t yet widely downloaded: select More Info, then Run Anyway.

The file is signed with the developer’s certificate (GDroid). SmartScreen trusts a new app once enough people have run it.

Install

  1. Open the .dmg and drag Tachyon onto Applications.
  2. Open Tachyon from Applications (or Launchpad).
  3. Add your service.
macOS Blocks It the First Time

“Apple could not verify ‘Tachyon’ is free of malware” shows for any app that isn’t notarized by Apple — Tachyon is signed with the developer’s own key, not a paid Apple Developer ID.

  1. Select Done on the message.
  2. Open System Settings → Privacy & Security and scroll down to Security.
  3. Next to “Tachyon was blocked…”, select Open Anyway, then confirm with your password or Touch ID.

macOS remembers it from then on. Prefer Terminal? xattr -dr com.apple.quarantine /Applications/Tachyon.app does the same in one go.

Run It

  1. Make it runnable: right-click → Properties → Permissions → Allow executing file as program (or chmod +x Tachyon-*.AppImage).

Nothing Happens?

Ubuntu 22.04 and newer leave out FUSE 2, which AppImages need: sudo apt install libfuse2 (Ubuntu 24.04: libfuse2t64), then try again.

Updating

Updates, one press away.

  1. Tachyon checksNow and then — at most every 12 hours, and only when you open it.
  2. New Release showsOn the start screen. Select it, then Update Now.
  3. It updates itselfDownloaded from the developer’s signed source, checked, installed and started again. Your services and settings stay.

Installed from Google Play? Play updates it for you.

Troubleshooting

If something gets in the way.

Android says “App not installed”

A copy from another source (for example Google Play versus a code) is already installed with a different signature. Keep updating the way you first installed, or uninstall that copy first (this removes its services and settings).

A Downloader code doesn’t work

Use the other code: both install the same file, from Dropbox and from Google Drive. Or open aftv.news/7607080 in the TV’s browser.

Google Drive warns it can’t scan the file

Google says this about every app file of this size. Select Download Anyway.

macOS says the app is damaged or can’t be opened

Follow the macOS steps (Privacy & Security → Open Anyway), or run xattr -dr com.apple.quarantine /Applications/Tachyon.app in Terminal.
