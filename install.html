Google Play

Recommended

For Android phones and tablets, Google TV and Android TV boxes that have the Play Store. It's the easiest install, and Google Play keeps Tachyon updated automatically.

Closed Testing Tachyon is in closed testing on Google Play, so the listing opens for testers only for now. The public release is coming soon. Until then, a Downloader code or the direct download gets you the same app.

  1. Open the Google Play Store on your phone, tablet or TV.
  2. Search for Tachyon: Fast IPTV Player, or open the listing with the button below.
  3. Select Install, then Open.
  4. Try the built-in offline demo, then add your service: an Xtream Codes login, an M3U playlist or an Emby server.

Downloader Code

Fire TV · TV Boxes

For Fire TV and TV boxes without Google Play. You type one short code in the free Downloader app by AFTVnews, and it always installs the newest Tachyon.

On a Fire TV or Fire TV Stick

  1. Install Downloader. On the home screen, go to Find → Search, type Downloader, pick Downloader by AFTVnews (orange icon) and select Get / Download.
  2. Let Downloader install apps. Go to Settings → My Fire TV → Developer Options → Install Unknown Apps and turn Downloader On.
    • No Developer Options? Go to Settings → My Fire TV → About, select your device name 7 times, then go back.
  3. Type the code. Open Downloader (allow access to files if it asks). In the box on the Home tab, enter a code and select Go:
    76070802336338
    • 7607080 is Shared From Dropbox. If you see a Dropbox page, select its Download button.
    • 2336338 is Shared From Google Drive. Drive says it can't scan the file for viruses: select Download Anyway.
  4. Install. When the download finishes, select Install.
  5. Open. Select Open, or Done and start Tachyon from your apps. When Downloader offers to delete the downloaded file, select Delete: Tachyon stays installed.

On a Google TV or Android TV Box

Has your box got Google Play? Google Play is easier and updates itself.

  1. Install Downloader. Open the Google Play Store, search for Downloader by AFTVnews and select Install. (Boxes without Play: use their own app store, or the direct download.)
  2. Let Downloader install apps. Go to Settings → Apps → Security & Restrictions → Unknown Sources and turn Downloader On. Menu names differ a little between models: look for "Unknown apps" or "Unknown sources".
  3. Type the code on Downloader's Home tab and select Go: 7607080 or 2336338
  4. Install, then Open.

Direct Download

APK File

For phones without Google Play, or to put the file on a box yourself. It's the same file the Downloader codes install: the newest Tachyon for phones, tablets and TVs.

  1. Download the file on the device with one of the buttons below. Google Drive shows a warning that it can't scan the file: select Download Anyway.
  2. Open it from your notifications or the Downloads folder.
  3. If Android asks, allow your browser (or file manager) to install apps, then go back.
  4. Select Install, then Open.

Updating Tachyon

  • From Google Play: nothing to do, it updates itself.
  • With a Downloader code: enter the same code again. It always installs the newest Tachyon over your current copy, and your services and settings stay. There's no need to uninstall first.
  • With the APK: download it again and open it. It installs over your current copy, keeping everything.

Pick One Way and Keep to It

If you installed from Google Play, update from Google Play. If you installed with a code or the APK, update the same way. Switching between the two can mean uninstalling Tachyon first, which removes your services and settings.

Troubleshooting

"App not installed"

Usually a copy of Tachyon from another source is already installed with a different signature, for example the Google Play copy when you install with a code, or the other way round.

Keep updating the way you first installed. If you really want to switch, uninstall the old copy first (this removes its services and settings; export your settings in the app first if you want to keep them). Also check that the device has enough free space.

Google Drive says it can't scan the file for viruses

Google Drive says this about every app file of this size. Select Download Anyway: the file is the official Tachyon app, signed with the same key as every release. Prefer to avoid the warning? Use code 7607080 (Dropbox) instead.

"For your security, your TV / phone is not allowed to install unknown apps"

Android asks once before an app other than Google Play can install apps. Select Settings on that message and turn on Allow from this source for Downloader (or your browser / file manager), then go back and select Install again.

On a Fire TV the switch is in Settings → My Fire TV → Developer Options → Install Unknown Apps. On Google TV / Android TV look in Settings → Apps → Security & Restrictions → Unknown Sources.

Downloader stops on a Dropbox page

Select the page's Download button. If nothing happens, use the Google Drive code 2336338, or open the direct download.

The Google Play listing says the app isn't available

Tachyon is in closed testing on Google Play, so the listing only opens for testers for now. The public release is coming soon. Until then, use a Downloader code or the direct download.
