macOS Blocks It the First Time — Why, and How to Open It

macOS shows “Apple could not verify ‘Tachyon’ is free of malware” for any app that isn’t notarized by Apple. Tachyon is signed with the developer’s own key, not with a paid Apple Developer ID, so macOS can’t check it against Apple’s list — it says this about every app downloaded outside the App Store that isn’t notarized.

  1. Select Done on the message.
  2. Open System Settings → Privacy & Security, scroll down to Security.
  3. Next to “Tachyon was blocked…”, select Open Anyway, then confirm with your password or Touch ID.
  4. Tachyon opens — macOS remembers it from then on.

Prefer Terminal? xattr -dr com.apple.quarantine /Applications/Tachyon.app does the same in one go.

Troubleshooting

If something gets in the way.

Android says “App not installed”

A copy from another source (for example Google Play versus a code) is already installed with a different signature. Keep updating the way you first installed, or uninstall that copy first (this removes its services and settings).

A Downloader code doesn’t work

Use the other code: both install the same file, from Dropbox and from Google Drive. Or open aftv.news/7607080 in the TV’s browser.

Google Drive warns it can’t scan the file

Google says this about every app file of this size. Select Download Anyway.

macOS says the app is damaged or can’t be opened

Follow the macOS steps (Privacy & Security → Open Anyway), or run xattr -dr com.apple.quarantine /Applications/Tachyon.app in Terminal.
