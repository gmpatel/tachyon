Service Sync: Set Up Your Services Once, Use Them Everywhere

Service Sync shares one set of IPTV services across your TV, phone and computer. Change a login on your main device and every other device follows.

Settings24 October 20263 Min ReadTVPhoneDesktop

Typing the same server, username and password into every TV, phone and computer in the house is tedious — and when your provider changes something, you'd do it all again. Service Sync fixes that: you set your services up once on a main device, and your other devices use the same services. Change one there, and the others follow by themselves.

How It Works

Settings → Services has two sides, on a bar at the top:

  • Set Up On This Device: the services you add on this device (what you've always had).
  • Sync From Main Device: the services of another Tachyon, read only.

Every device has a short Sync Code, shown on its Set Up On This Device side under Service Sync, with a Copy Code button. A device that syncs types the main device's code once, and from then on uses its services.

On the Main Device

  1. Open Settings → Services and stay on Set Up On This Device.
  2. Add your services as usual.
  3. In the Service Sync box, check that Use My Services on Other Devices is on (it is by default).
  4. Note the Sync Code — or select Copy Code to send it to yourself.

The setup is encrypted on the device before it's sent, and kept sealed on the server. The device also keeps its setup there as its own backup, even while sharing is off.

On Every Other Device

  1. Open Settings → Services and pick Sync From Main Device.
  2. In Connect Your Main Device, type the main device's code and select Sync Services.
  3. The main device's services appear, ready to watch. Its card shows Sync Now and Change Code.

Leave Main Device Full ID empty unless Tachyon asks for it. It's needed only in the rare case that two devices share the same short code; it's shown under the code on the main device, and after the first sync it's filled in by itself.

Tip

On a TV, typing the code with the remote is fine — it's short. Or open Easy Settings on your phone, where the Services tab has the same two sides.

When Changes Arrive

A device that syncs checks the main device:

  • when Tachyon starts, and when it comes back from the background;
  • when you open Settings;
  • every hour while it runs;
  • whenever you select Sync Now.

A check that finds nothing new costs a few bytes. Everyday changes on the main device — like the volume or a filter — never count as a change. And a sync never reloads a library that's still fresh: libraries update on their own schedule (Big Libraries).

What You Can and Can't Do on a Synced Device

  • Synced services are read only: open one to see its details (each password shows as dots until you press its eye), but change it on the main device.
  • Everything else stays this device's own: favorites, Continue Watching, settings, the look.
  • This device's own services aren't lost. Pick Set Up On This Device and they come back at once.

Stopping Sharing

Turning off Use My Services on Other Devices on the main device asks first (Stop Sharing Your Services?). Devices that sync from it then lose its services at their next check and show Your Main Device Stopped Sharing, with Use This Device's Services or Sync From Another Device. Turn sharing on again and they come back by themselves — the code stays the same.

Questions and Answers

Does a synced device use another connection on my plan?

Each device that plays uses one stream, as always. Two devices watching at the same time need a plan with two connections. Syncing itself streams nothing.

Is my password safe?

The setup is encrypted on the device before it leaves, and it's stored sealed on the server. Anyone with your Sync Code can sync your services, so share the code only with your own devices — and turn sharing off if you no longer need it.

Can a synced device change a service?

No. Change it on the main device; the others follow at their next check, or at once with Sync Now.
